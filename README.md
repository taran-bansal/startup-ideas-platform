# 🚀 Startup Ideas Platform

A Flutter-based platform for submitting, browsing, and voting on innovative startup ideas. Built with ❤️ using Flutter and GetX for state management.

![App Screenshot](https://via.placeholder.com/300x600/0d80f2/ffffff?text=Startup+Ideas+App)

## ✨ Features

- **Submit Ideas**: Share your innovative startup ideas with the community
- **Browse & Vote**: Discover and vote on the most promising ideas
- **Leaderboard**: Track the top-rated startup ideas
- **Modern UI**: Clean and intuitive user interface
- **Responsive Design**: Works on both mobile and tablet devices

## 🎨 Design System

- **Primary Color**: #0d80f2
- **Text Colors**: 
  - Primary: #111418 
  - Secondary: #60758a
- **Background**: #ffffff
- **Secondary Background**: #f0f2f5
- **Font Family**: Inter (primary), Noto Sans (fallback)
- **Border Radius**: 8px (md), 12px (lg)

## 📱 Screens

1. **Submit Idea**
   - Form to submit new startup ideas
   - Fields for name, tagline, and description
   
2. **Ideas List**
   - Browse all submitted ideas
   - Sort by rating or votes
   - Upvote your favorite ideas
   
3. **Leaderboard**
   - Top-rated ideas
   - Visual ranking system
   - Quick view of key metrics

## 🛠️ Tech Stack

- **Framework**: Flutter
- **State Management**: GetX
- **Architecture**: MVC (Model-View-Controller)
- **Dependency Injection**: GetX
- **Theming**: Custom theme with support for light/dark mode

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Android Studio / VS Code
- Android Emulator or physical device

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/taran-bansal/startup-ideas-platform.git
   cd startup-ideas-platform
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```
